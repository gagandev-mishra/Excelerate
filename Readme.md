# Excelerate Dashboard

This dashboard is created at the time of my one month of Data Analyst internship at Excelerate platform where we have provided a very messy datasets of their own platform on that have to done EDA, transform the data using the Microsoft Excel, then finally created an interactive Dashboard using Power BI.
